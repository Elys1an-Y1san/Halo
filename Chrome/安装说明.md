# 映光 · Halo 1.0.0

新名称、新图标、中文暖色界面。视频页与工具栏使用同一套操作：环境光开关、模糊、扩散、亮度，以及「柔和 / 影院 / 漫射」三个预设。两个网站的设置分别保存。

## Safari

解压 Halo-Safari-1.0.0.zip，打开其中的 Halo.app，在引导界面进入 Safari 扩展设置，启用「映光 · Halo」，允许访问 www.youtube.com 和 www.bilibili.com，刷新已有视频页。

这是本机开发签名的 macOS 应用，未做开发者证书签名或公证，也不是 App Store 安装包。沿用旧版本的扩展标识以保留本机设置；安装前退出 Safari，将旧的 Ambient Light for Safari.app 移至废纸篓，避免两个同标识版本并存。如果 Safari 要求允许未签名扩展，需要在开发者设置中开启此开发选项。其他电脑的系统安全限制可能不同。

## Chrome

解压 Halo-Chrome-1.0.0.zip。打开 chrome://extensions，开启开发者模式，点击「加载已解压的扩展程序」，选择含 manifest.json 的 Chrome 文件夹。固定工具栏中的映光图标。请停用其他同类环境光扩展，避免同时渲染两层光晕。

这是 Manifest V3 本地扩展包，不是应用商店发布版，也不是可直接拖入安装的 CRX 文件。

安装步骤依据：https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked

## 使用

- 视频页右下角「映光」打开设置；模糊控制柔和程度，扩散控制光晕覆盖范围。
- 工具栏弹窗可选择网站，调整该网站的设置；「在当前视频页展开」需要当前页已获授权且加载了播放器。
- 重做的界面集中于常用光效控制。原项目的复杂高级设置不在新版界面中展示。
- B 站支持普通视频页，并包含番剧页面适配代码；直播页面不在本版范围。

## 源码与开源致谢

Source 文件夹包含原生工程、网页扩展源码与打包脚本。build-chrome.sh 生成 Chrome 文件夹；build-macos.sh 同时构建原生应用，需要 Node.js 22 与 Xcode。已附完整可安装构建产物，无需重新编译。

YouTube 渲染核心来自 Wessel Kroos 的 youtube-ambilight 2.38.17（18d17188e5562e5ee913f005192d30c9a60be078），保留 MIT 许可与作者署名。映光添加独立界面、B 站适配与 Safari 兼容修改。设置保存在浏览器本地，默认关闭崩溃上报。
