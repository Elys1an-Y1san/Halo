# 映光 Halo Windows 安装包

先把整个 ZIP 解压到一个文件夹，再运行安装器。直接在压缩软件中双击脚本会缺少插件文件。

## 自动加载插件

双击「一键安装.cmd」。安装器把插件复制到 `%LOCALAPPDATA%\Halo\Extension`，下载官方 Chrome for Testing 稳定版，并创建桌面「映光 Halo」快捷方式。首次需要联网下载浏览器，可能花费几分钟。下载完成后会打开哔哩哔哩。

从这个桌面快捷方式打开浏览器，进入视频页，点击右下角「映光」。支持 Windows 10 / 11 的 64 位系统；不需要管理员权限。

这是独立的测试版浏览器，使用 `%LOCALAPPDATA%\Halo\BrowserProfile` 保存自己的设置和登录状态。它不会读取已有 Chrome 的配置，也不会成为默认浏览器。Chrome for Testing 不自动更新，定期重新运行安装器获取最新稳定版。更新前先关闭这个独立浏览器。

## 使用已经安装的 Chrome

双击「使用已有Chrome.cmd」。安装器复制插件并打开 `chrome://extensions/`，把插件路径复制到剪贴板。

1. 在扩展页右上角打开「开发者模式」。
2. 点击「加载已解压的扩展程序」。
3. 在文件夹选择窗口粘贴 `%LOCALAPPDATA%\Halo\Extension`，确认加载。

首次需要本人在 Chrome 中确认。如果之前已从其他文件夹加载过映光，先移除旧版，再加载固定目录中的新版；首次迁移的设置可能不会沿用。后续更新重新运行这个安装器，再到扩展页点击映光卡片上的刷新图标，刷新视频页。

## 文件与卸载

安装目录固定，更新时只替换插件文件。浏览器设置保存在浏览器配置中。要卸载现有 Chrome 中的插件，先在扩展页移除映光。要移除独立浏览器，先关闭它，再删除 `%LOCALAPPDATA%\Halo` 和桌面快捷方式；删除此目录也会删除独立浏览器的登录状态与设置。

脚本仅在本次安装进程内运行，不修改系统 PowerShell 执行策略或 Chrome 企业策略。浏览器从 Google 官方 HTTPS 地址下载，下载后核对源站提供的归档完整性值。`payload.json` 用于发现插件文件损坏。

项目与更新：[Elys1an-Y1san/Halo](https://github.com/Elys1an-Y1san/Halo)。插件版本查询在面板底部，不需要登录。

当前包在 macOS 上检查了脚本语法、文件部署和包完整性，尚未进行 Windows 实机运行验收。
