# 安装与更新

## Chrome

1. 获取本仓库，找到根目录的 `Chrome` 文件夹。
2. 打开 `chrome://extensions`，启用开发者模式。
3. 选择「加载已解压的扩展程序」，选中 `Chrome`。
4. 允许网站访问，刷新已有视频页，在右下角「映光」打开设置。

更新时，用新版 `Chrome` 替换原文件夹，在扩展管理页点击重新加载，刷新视频页。保留扩展安装路径以保留本地设置。

## Safari

1. 将 `Safari/Halo.app` 放入「应用程序」，打开应用。
2. 在 Safari 扩展设置中启用映光，并允许视频网站访问。
3. 刷新视频页，打开右下角映光面板。

当前应用是 macOS 本地开发签名构建，未公证。Safari 如需开发设置，可在「设置 → 高级」启用网页开发者功能，再在开发者设置中允许未签名扩展。首次安装和跨机器启用受系统签名设置影响。需要正式分发时，可在 Xcode 工程里配置自己的开发团队并签名、公证。

更新时退出 Safari，以新版应用替换原应用，再重新打开；避免安装两个使用相同扩展标识的版本。

## 查询更新

页内面板和工具栏弹窗均有「检查更新」。查询公开仓库 `Elys1an-Y1san/Halo` 最新正式 Release，无需登录。出现新版时，点击「查看新版」前往发行页，按上面的步骤手动替换。

查询只发送版本元数据请求，不发送正在浏览的网址，不下载或执行远程代码。匿名查询可能受 API 限流或网络影响；界面提供重试提示。

## 运行范围

YouTube 和哔哩哔哩的适配代码涵盖普通视频、番剧、直播及嵌入播放器。网站登录、付费内容和全部站内导航组合仍需实际安装验收。现有浏览器演示使用本地动态视频与接口夹具；完整证据见 [QA](QA.md)。
