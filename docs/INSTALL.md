# 安装与更新

## Chrome

1. 获取本仓库，找到根目录的 `Chrome` 文件夹。
2. 打开 `chrome://extensions`，启用开发者模式。
3. 选择「加载已解压的扩展程序」，选中 `Chrome`。
4. 允许网站访问，刷新已有视频页，在右下角「映光」打开设置。

更新时，用新版 `Chrome` 替换原文件夹，在扩展管理页点击重新加载，刷新视频页。保留扩展安装路径以保留本地设置。

## Windows 安装包

从[发行页](https://github.com/Elys1an-Y1san/Halo/releases/latest)下载 Windows ZIP，完整解压后打开包内的「开始使用.md」。可以使用独立浏览器安装器，也可以部署后在已有 Chrome 中加载。

脚本无法运行时，直接打开 `chrome://extensions/`，启用「开发者模式」，选择「加载已解压的扩展程序」，选中解压目录里的 `Chrome` 文件夹。安装后保留该文件夹；更新时覆盖同一路径并重新加载扩展。

## Safari

1. 将 `Safari/Halo.app` 放入「应用程序」，打开应用。
2. 在 Safari 扩展设置中启用映光，并允许视频网站访问。
3. 刷新视频页，打开右下角映光面板。

当前应用使用 Apple Development 证书签名，未公证。首次安装和跨机器启用受系统开发设置影响。需要正式分发时，应使用 Developer ID 签名并公证。

从旧本地签名版本迁移时，系统可能要求确认新版应用继续使用旧版数据容器。此确认由本人在系统提示中完成。

1.0.3 起支持面板内更新。首次从旧版迁移时，退出 Safari，以新版应用替换原应用，再重新打开。避免同时安装两个使用相同扩展标识的版本。

## 查询更新

页内面板和工具栏弹窗均有「检查更新」。查询公开仓库 `Elys1an-Y1san/Halo` 最新正式 Release，无需登录。Safari 出现新版后，点击「安装更新」，原生窗口显示下载和安装进度，完成后刷新视频页。Chrome 点击「查看新版」前往发行页，再按上面的步骤替换文件夹。

查询只发送版本元数据请求，不发送正在浏览的网址。Safari 的安装步骤由原生更新器处理，校验发行包签名后替换应用。匿名查询可能受 API 限流或网络影响；界面提供重试提示。
