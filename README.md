# 映光 · Halo

为 YouTube、哔哩哔哩和 X 添加随视频变化的环境光。支持 Chrome、Edge、Safari 和桌面版 Firefox。

1.2 起使用独立的视频采样与渲染引擎。三个站点共用帧调度、设置通信和错误恢复，不再加载旧项目的脚本、界面或注入桥接。播放器延迟加载时自动等待，切换视频后自动重新连接。

[下载安装包](https://github.com/Elys1an-Y1san/Halo/releases/latest) · [观看演示](https://elys1an-y1san.github.io/Halo/) · [反馈问题](https://github.com/Elys1an-Y1san/Halo/issues)

## 使用

首次安装后，在首个可用的视频页面显示带产品标志的全屏透明引导。页面与视频保持可操作，随时可以跳过，并支持减少动态效果。引导会带你对比环境光，再打开实际面板调整亮度；跳过或完成后不再自动弹出。可从「偏好 → 使用引导」重看，普通版本升级不会触发首次引导。

打开视频页，点击「映光」。选择柔和、影院或漫射，也可以用滑块或直接输入数值，调整光边柔和程度、覆盖范围和亮度。

- 从页面面板开启环境光时，光效沿面板圆角边框向外展开；开启后保留柔和的边缘漫反射。关闭时收回，快速反向切换沿用当前进度；键盘操作及减少动态效果模式直接切换。
- 点击「查看原画」暂时隐藏环境光，再次点击恢复。关闭面板、切换窗口或关闭弹窗也会结束对比，不改保存的开关状态。
- 「重置光效」只重置三个光效参数，保留开关状态。误操作可点击「撤销」。
- 光效按时间平滑过渡，暗场收敛外围光，明亮画面限制光效强度；不改变视频原画，也不识别或裁切黑边。视频禁止像素读取时仍保留平滑光效，面板提示亮度自适应不可用。
- 新用户默认自动性能档，在 15–30 帧/秒之间按采样耗时与调度延迟调节：持续压力下降档，连续稳定后恢复。原有手动档保留，节能 15、均衡 30、流畅 60 帧/秒均为采样上限，不改变视频帧率。
- 滚动时复用视频列表，并合并播放器发现任务；隐藏标签页暂停发现与采样，返回后自动恢复。暂停播放时保留最后一帧光效。
- 拖动页面上的「映光」按钮可自由移动，位置按网站记忆；Alt + 方向键可微调。在「偏好 → 位置」选择自动、左侧或右侧可复位。
- 哔哩哔哩滚动进入页面小窗时停止环境光，回到主播放器后自动恢复；不会改变保存的开关状态。
- X 信息流优先跟随可见的播放中视频；滚出画面后停止采样，媒体弹窗中的视频优先。

面板会显示正在生效、等待视频、暂停渲染或连接失败等状态。采样失败可重新采样；工具栏连接失效时可点击「刷新视频页」，浏览器能确认网站权限缺失时提供授权操作。刷新会重新加载当前页面，恢复操作不会自动切换到其他标签页。环境光关闭时仍可预调参数，下次开启后生效。性能、位置和更新入口在「偏好」页中。

设置保存在浏览器本地，无需账号。版本查询不发送浏览网址，不包含崩溃上报。

## 安装

从发行页下载对应安装包并解压。源码仓库不再收录生成的浏览器包和应用；本地构建方法见下文。当前源码为 1.3.1，发行页版本以实际发布为准。

| 浏览器 | 安装方式 |
| --- | --- |
| Chrome | 打开 `chrome://extensions`，启用开发者模式，点击「加载已解压的扩展程序」，选择包内 `Chrome` 文件夹 |
| Edge | 打开 `edge://extensions`，启用开发者模式，点击「加载解压缩的扩展」，选择包内 `Chrome` 文件夹 |
| Windows Chrome | 解压 Windows 包，按包内「README.md」操作；也可按上面的方式加载 `Chrome` 文件夹 |
| Firefox 128+ | 打开 `about:debugging#/runtime/this-firefox`，点击「临时载入附加组件」，选择包内 `manifest.json` |
| Safari | 将包内 `Halo.app` 放到「应用程序」并打开，在 Safari 扩展设置中启用映光、允许网站访问 |

安装后刷新已有的视频页。不要移动或删除已加载的扩展文件夹。

Firefox 包尚未签名，只供临时加载，重启浏览器后需要重新加载。Safari 本地构建使用开发证书，未公证，首次启用受系统开发设置影响。跨浏览器真实站点运行情况仍需分别验证。

## 更新

「偏好 → 更新与安装」在插件内检查和安装更新。查询失败、限流或校验失败会显示原因，可在原页重试。

- Safari 通过原生更新器下载和安装。
- Chrome / Edge 解压安装版：首次点击「安装更新」时选择原安装文件夹并授权写入。插件下载官方发行包，验证 SHA-256、包内版本和权限，备份原文件后写入，再重启确认版本；无需跳转下载或手动解压。失败会回滚，更新页中断后可恢复。浏览器可能再次要求文件夹授权。
- 商店安装版使用浏览器更新源，准备完成后点击「重启扩展」。更新源尚未提供新版时会提示稍后重试。
- 已发布的旧版不含此安装器，需要先换装一次带此功能的版本。未经实测的浏览器或操作系统不视为已通过升级验收。
- 当前 Firefox 包未签名，只能按页面步骤临时载入更新。由浏览器自动安装更新需要发布签名版本，并提供商店或自托管更新源；本项目尚未发布这一渠道。

## 开发

需要 Node.js 22+、Python 3。构建原生应用还需要 macOS、Xcode 和可用的 Apple 签名证书。

```sh
cd Source
npm ci --ignore-scripts
npm run build
python3 package-halo.py
```

生成 `Builds/chromium/<版本>/Chrome/`、`Builds/firefox/<版本>/Firefox/`、原生扩展资源及未签名测试包。构建完整 Safari 应用运行 `./build-macos.sh`；构建 Windows 安装包在仓库根目录运行 `python3 Source/package-windows.py`。

```sh
# 在 Source 中运行
node --test tests/*.test.cjs
node tests/render-regression.cjs
python3 tests/package-check.py
python3 tests/ui-fixture/serve.py
```

本地预览为 `http://127.0.0.1:8765/preview.html`。`suite.html` 检查已有流程，`features.html` 检查撤销、对比、精确输入及渲染适配。运行浏览器测试时保持测试页可见，视频移出可视区会暂停采样。测试页使用模拟扩展接口，不替代真实视频网站验收。

可选浏览器测试需要另行提供 Playwright 和对应浏览器：`node tests/browser-check.cjs` 运行交互回归；`node tests/performance.cjs` 自行启动本地测试服务，统计多视频滚动、内容变化、暂停和模拟隐藏场景中的扫描、样式读取、布局读取及采样次数，并检查性能预算和恢复行为。设置 `HALO_NO_VIDEO_CALLBACKS=1` 可验证备用帧调度。新增光效和恢复测试可在测试服务运行时执行 `node tests/p1-browser.cjs`，使用真实画布与视频、模拟扩展通信和负载，检查平滑、暗场、亮度约束、自动档恢复及连接恢复。

性能结果保存在 `.build/performance/`，这些工作量计数不代表真实视频网站的 CPU 降幅。

源码与测试放在 `Source/`，演示页和签名更新源放在 `docs/`。本地构建统一放在 `Builds/`，按 `chromium/`、`firefox/`、`safari/` 分类，每类保留当前版和三个历史版本；`current` 指向当前版。完成原生构建后运行 `python3 Source/package-release.py` 生成各类安装包。

构建产物、截图和工作记录不提交；文档仅保留 README 与 AI 指令文件。`LICENSE`、程序页面和签名更新源随源码保留。
